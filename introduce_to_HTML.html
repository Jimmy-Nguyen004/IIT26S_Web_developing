Basic HTML Tutorial

HTML stands for HyperText Markup Language. It is used to create and structure web pages.

Basic Structure of an HTML Page

A simple HTML page contains HTML, HEAD and BODY tags.

<html>
    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Hello World</h1>
    </body>
</html>

HTML Tags

<HTML>

The HTML tag contains all the content of an HTML page. It is the main element of the document.

<HEAD>

The HEAD tag contains information about the website, such as the page title.

<BODY>

The BODY tag contains everything that is shown on the webpage, such as text, images and links.

<P>

The P tag is used to create paragraphs of text.

Common HTML Tags

  • <html> - Contains the whole HTML document
  • <head> - Contains information about the page
  • <body> - Contains visible page content
  • <p> - Creates a paragraph
  • <img> - Displays an image
  • <a> - Creates a link
  • <br> - Creates a line break
  • <h1> to <h6> - Creates headings

Conclusion

HTML uses different tags to structure a webpage. Tags can be placed inside other tags to create the structure and content of a website.
