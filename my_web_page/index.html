What I learnt

HTML

Tags given the page its structure. Forms need labels and good input types, and the browser sends the data to a server with GET or POST.

CSS

Selectors pick the elements. Flexbox is good for one row, grid for rows and columns, and media queries make the page work on phones.

JavaScript

Reading values from inputs, checking them, using loops and functions, and writing the answer back into the page.
