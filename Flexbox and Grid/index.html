Flexbox and Grid

This page shows how CSS Grid and Flexbox work. The menu on the top is made with Flexbox and the pictures are placed with Grid.

How the content is laid out

The pictures are inside a div with the class grid-container. I gave it display: grid so all the boxes inside it become grid items. Then grid-template-columns: repeat(3, 1fr) makes three columns that are all the same width. The boxes fill the grid from left to right, and when a row is full they continue on the next row.

The menu works with Flexbox. The icon-bar div has display: flex, which puts all the links next to each other in a row. Every link has flex: 1, so they all get the same width and fill the whole bar.

Settings I used

These are the settings that are needed and what they do.

Grid

  • display: grid -> turns the container into a grid.
  • flex: 1 -> makes every item grow to the same size.
  • flex-direction: column -> puts the items under each other instead of in a row.

How it changes on different screens.

I used media queries to change the layout when the screen gets smaller. You can test this by making the browser window smaller.

  • Big screen (over 800px): the grid has 3 columns and the menu is in one row.
  • Tablet (500px - 800px): the grid changes into 2 columns.
  • Phone (under 500px): the grid has only 1 column, the menu links go under each other and the feature lists below are on top of each other.

The images have width: 100%, so they get bigger and smaller together with the box.

Features

Here are the main features of Flexbox and Grid and how to use them. The two lists are next to each other with Flexbox.

Flexbox

  • flex-direction chooses a row or a column, for example flex-direction: column;
  • justify-content moves items along the row, for example center or between.
  • align-items lines up items vertically, for example align-items: center;
  • flex-wrap lets items go to the next line when there is no space: flex-wrap: wrap;
  • flex sets how much an item can grow: flex: 1;
  • gap adds space between the items.

Grid

  • grid-template-columns sets the columns, for example 200px 1fr.
  • grid-template-rows sets the rows the same way.
  • fr is a unit that means one part of the free space.
  • repeat() is a shorter way to write columns. repeat(3, 1fr) is the same as 1fr 1fr 1fr.
  • grid-column makes an item wider, for example grid-column: span 2;
  • gap adds space between rows and columns.
