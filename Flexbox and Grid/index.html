Flexbox and Grid

This page shows how CSS Grid and Flexbox work. The menu on the top is made with Flexbox and the pictures are placed with Grid.

How the content is laid out

The pictures are inside a div with the class grid-container. I gave it display: grid so all the boxes inside it become grid items. Then grid-template-columns: repeat(3, 1fr) makes three columns that are all the same width. The boxes fill the grid from left to right, and when a row is full they continue on the next row.

The menu works with Flexbox. The icon-bar div has display: flex, which puts all the links next to each other in a row. Every link has flex: 1, so they all get the same width and fill the whole bar.
